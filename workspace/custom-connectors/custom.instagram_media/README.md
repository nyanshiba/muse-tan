# Instagram Collection Media (embed, no login)

Instagram の保存コレクションに入れた服を、キャプションではなく**画像そのものを自分の目で読んで**選ぶためのカスタムコネクタです。キャプションは服の形を取り違えることがあります（プリーツのキュロットが「バルーンスカート」と書かれていた実例がありました）。説明文だけでは服は選べません。

## x_thread との違い：ビルトインの上流がある

同じリポジトリの `custom.x_thread` は単体で完結しますが、こちらは二段構えです。

- **上流（ビルトイン依存）**：コレクションのメタデータ（permalink の一覧）は、Muse 本体に組み込まれた Instagram コネクタの `instagram-cli saved-posts` で取得します。ここだけログイン済みアカウントが必要です。同梱の `bin/fetch_collection.py` はその薄いラッパーで、アカウント ID とコレクション ID は引数で渡します（コードには埋め込んでいません）。この CLI は Muse 本体の側のもので、このリポジトリには含まれません。
- **下流（このコネクタの本体）**：`bin/instagram_media.py` が、permalink から shortcode を取り、ログインなし・Cookie なしで公開 embed ページ（`/p/{shortcode}/embed/captioned/`）を読み、埋め込み JSON から全子メディアの画像 URL を得て、その場でダウンロードします。カルーセルの全子、単一画像、リールのポスター（動画は取得しません）に対応します。

つまり「匿名で読める」のは画像側だけで、コレクションの所在を知る部分はビルトインの上流に依存します。ここを取り違えると設計を誤るので、明記しておきます。

## 設計

- **small のみ**：保存するのは長辺 640px に縮小した JPEG（1枚 36〜57KB 実測）。原寸はコレクション全件で約1GB級になるところ、代表画像125件で 8.2MB に収まりました。細部が読めない時だけ原寸へ上げる想定です。
- **取得と保存は同時**：CDN の署名 URL は約4日で失効するので、パースした実行の中でダウンロードまで終えます。
- **直列＋接続再利用**：リクエストは直列化し、ホストごとに keep-alive を回します。HTTP 429 / 403 が返ったら即停止（終了コード5）し、再試行や回避はしません。
- **フォールバックは暫定扱い**：embed がメディアを返さない投稿は投稿ページの `og:image`（640×640 中央切り抜き）を暫定の代表として保存し、マニフェストに明記します。全身が切れている前提で、選定では「保留」格です。
- **マニフェスト**：`manifest.json` に shortcode ごとの投稿者・permalink・成否・注記を残します。子の数がメタデータと食い違う場合は、黙って通さず注記します。

## 使い方

```text
# 上流：コレクションのメタデータを更新（要 instagram-cli）
python3 bin/fetch_collection.py --account-id <id> --collection-id <id>

# 下流：全件の代表画像（子1枚目・small）を取得。既存ファイルはスキップ
python3 bin/instagram_media.py tops

# 候補に絞ってから、全子（small）を取得
python3 bin/instagram_media.py children <shortcode> [more...]

# 単体（permalink または shortcode）
python3 bin/instagram_media.py one <permalink-or-shortcode> [--children]
```

保存先は `~/workspace/instagram/media/<shortcode>/<index>-small.jpg` です。

## 注意

- Instagram の利用規約は自動収集を禁止する側です。この経路はその前提を明記した上で、個人の参照用途・小規模・オンデマンドに限って使います。ログイン Cookie を使う経路は、アカウント停止リスクがあるため意図的に採用していません。
- 取得した画像そのものは公開・共有・再配布しません。このリポジトリにも画像は含まれません。公開しているのはコードと文書だけです。
- embed の仕様は Instagram 側の都合で予告なく変わり得ます。壊れたら「上流の変更」として扱ってください。
